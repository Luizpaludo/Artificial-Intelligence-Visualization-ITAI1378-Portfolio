# Module 01: Welcome - Computer Vision Fundamentals

## Overview

This module introduced the basic concepts that will be used throughout the course. The activities focused on learning how to use GitHub, creating and working with Jupyter Notebooks, and understanding how computer vision is used in real-world applications.

The goal of this module was to become familiar with the tools that will be used during the semester while also learning about the fundamentals of computer vision.

---

## Learning Objectives

After completing this module, I was able to:

- Create and manage a GitHub repository.
- Make commits and update files using GitHub.
- Create and use a Jupyter Notebook.
- Write Markdown and Python code in a notebook.
- Research a real-world computer vision application.
- Understand the advantages and challenges of computer vision technology.

---

## Activities

### Activity 1 – GitHub and Jupyter Notebook

In this activity, I created my first GitHub repository and learned how to work with Jupyter Notebook. I practiced creating Markdown cells, writing simple Python code, saving notebooks, and uploading files to GitHub using GitHub Desktop.

### Activity 2 – Computer Vision Research

For this activity, I researched a real-world application of computer vision and analyzed how the technology works. The assignment also included discussing its benefits, challenges, and possible future developments.

This activity helped me understand that computer vision is used in many industries and can improve efficiency, safety, and automation.
