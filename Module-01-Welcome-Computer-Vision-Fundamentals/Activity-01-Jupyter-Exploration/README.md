# Activity 01: Jupyter Exploration

## Overview

The purpose of this activity was to become familiar with GitHub and Jupyter Notebook. I learned how to create a GitHub repository, edit a README file, make commits, and create a simple Jupyter Notebook with both Markdown and Python code.

This activity also introduced the workflow for saving notebooks and uploading them to GitHub.

---

## Objectives

- Create a GitHub repository.
- Learn the GitHub interface.
- Create and edit a README file.
- Make the first commit.
- Create a Jupyter Notebook.
- Write Markdown and Python code.
- Upload the notebook to GitHub.

---

## Project Description

For this assignment, I created a GitHub repository called **jupyter-exploration**. Inside the notebook, I added a Markdown cell and wrote a simple Python program to practice using variables, user input, and formatted output.

Although I already had some experience with GitHub from a previous class, this activity helped me learn a better workflow using GitHub Desktop to upload my projects.

This activity helped me become more comfortable using GitHub and Jupyter Notebook. I improved my understanding of version control and learned a more organized way to upload projects. These skills will be useful for the rest of the course.
