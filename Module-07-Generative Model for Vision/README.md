# Module 07: Generative Models for Vision

## Overview

This module introduced generative models for computer vision and how they are used in modern AI workflows. Unlike previous modules that focused on analyzing images through classification, object detection, and segmentation, this module explored how AI can generate new images from text prompts or existing images.

The module emphasized the practical use of pretrained generative models such as Stable Diffusion, FLUX, and DALL-E, focusing on how computer vision engineers use these tools in real-world applications rather than how the models are trained.

---

## Learning Objectives

After studying this module, I was able to:

- Understand the differences between image analysis and image generation.
- Identify the major families of generative AI models.
- Learn how prompt engineering influences image generation.
- Understand image-to-image workflows such as img2img, inpainting, and ControlNet.
- Explain how synthetic data can improve computer vision models.
- Recognize the ethical and legal challenges associated with generative AI.

## What I Learned

This module expanded my understanding of computer vision by introducing generative AI. I learned that generative models are not designed to replace traditional computer vision techniques, but instead complement them by creating synthetic images, improving datasets, restoring images, and accelerating development workflows. I also learned that responsible use of these technologies requires understanding their limitations, potential biases, copyright concerns, and ethical implications.
