# Module 09: AI Agents for Computer Vision

## Overview

This module introduced AI agents and their role in modern computer vision systems. Unlike traditional computer vision models that only analyze images, AI agents combine perception, reasoning, action, and memory to solve more complex tasks.

The module explained how computer vision models, Vision Language Models (VLMs), and reasoning systems can work together to build intelligent applications capable of making decisions and interacting with their environment.

---

## Learning Objectives

After completing this module, I was able to:

- Define what an AI agent is.

- Explain how computer vision serves as the perception component of an AI agent.

- Compare traditional software with AI agent systems.
- Identify practical applications of AI agents in computer vision.

## Key Concepts

One of the most important ideas from this module is that computer vision becomes the "eyes" of an AI agent. Instead of only detecting objects, an agent can observe a scene, reason about what is happening, decide what action to take, and remember previous events. This allows AI systems to support more advanced applications such as workplace safety monitoring, document processing, retail automation, and intelligent assistants.

The module also emphasized that AI agents are not always the best solution. In many situations, simple rule-based software remains faster, less expensive, and easier to maintain.
