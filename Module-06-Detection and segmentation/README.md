# Module 06: Object Detection and Image Segmentation

## Overview

This module introduced modern computer vision techniques for object detection and image segmentation. Unlike image classification, which predicts a single label for an image, object detection identifies and locates multiple objects, while image segmentation provides a more detailed understanding by outlining the shape of each object.

During this lab, I worked with YOLO11 for object detection, YOLO11-seg for instance segmentation, and compared these models with the Segment Anything Model (SAM 2). I also explored evaluation metrics commonly used in computer vision and began planning a project that combines the concepts learned throughout the course.

---

## Learning Objectives

After completing this module, I was able to:

- Understand the differences between image classification, object detection, and image segmentation.
- Run object detection using YOLO11.
- Perform instance segmentation using YOLO11-seg.
- Compare YOLO and SAM 2.
- Interpret evaluation metrics such as IoU, Precision, Recall, and mAP.
- Apply these concepts to a real-world computer vision project.
