# Module 03: Machine Learning for Computer Vision

## Overview

This module introduced the fundamentals of machine learning for computer vision. The focus was on understanding how image features can be extracted and used by machine learning algorithms to classify images.

Through a hands-on lab, I explored the complete workflow of a traditional computer vision system, including feature extraction, model training, and performance evaluation.

---

## Learning Objectives

After completing this module, I was able to:

- Understand the role of machine learning in computer vision.
- Learn how image features are extracted.
- Compare different machine learning algorithms.
- Evaluate model performance using classification metrics.
- Understand the complete machine learning pipeline.

This module helped me understand how traditional machine learning techniques can be applied to computer vision tasks.
