# Feature Extraction and Algorithm Comparison

## Overview

This project explores how classical machine learning techniques can be applied to computer vision. The main objective was to extract meaningful features from images, train different machine learning models, and compare their performance on the same dataset.

This lab demonstrates the complete workflow of a traditional computer vision system, from feature extraction to image classification and model evaluation.

---

## Objectives

After completing this project, I was able to:

- Understand the workflow of a classical computer vision system.
- Apply different feature extraction techniques.
- Train and compare multiple machine learning algorithms.
- Evaluate model performance using classification metrics.
- Understand the strengths and limitations of different algorithms.

---

## Project Description

For this project, I completed **Lab A: Comprehensive Feature Extraction and Algorithm Comparison**.

The notebook explores several feature extraction techniques and compares the performance of multiple machine learning algorithms for image classification. The project also demonstrates how feature extraction influences model performance and why proper model evaluation is important when developing computer vision applications.
