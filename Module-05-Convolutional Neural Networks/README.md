# Module 05: Convolutional Neural Networks

## Overview

This module introduced Convolutional Neural Networks (CNNs), one of the most important deep learning techniques used in computer vision. Unlike traditional neural networks, CNNs automatically learn image features through convolutional layers, making them highly effective for image classification tasks.

During this module, I explored how CNNs process images, experimented with different training parameters, and compared their performance with the traditional neural network developed in the previous module.

---

## Learning Objectives

After completing this module, I was able to:

- Understand how Convolutional Neural Networks work.
- Train a CNN for image classification.
- Apply data augmentation techniques.
- Experiment with different hyperparameters.
- Compare CNNs with traditional neural networks.
- Evaluate model performance and generalization.

## Project

### CNN Chihuahua or Muffin

In this project, I trained and evaluated a Convolutional Neural Network capable of classifying images as either a Chihuahua or a muffin. I also experimented with different training configurations to improve the model's performance.
