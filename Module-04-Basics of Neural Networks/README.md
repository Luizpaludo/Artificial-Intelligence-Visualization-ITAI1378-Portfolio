# Chihuahua or Muffin

## Overview

The purpose of this project was to explore deep learning for image classification using PyTorch. The goal was to build, train, and evaluate a neural network capable of distinguishing between images of Chihuahuas and muffins.

Although these two categories appear very different at first, many images share similar visual characteristics, making this an interesting image classification problem.

---

## Objectives

After completing this project, I was able to:

- Prepare image datasets for deep learning.
- Preprocess images before training.
- Build and train a neural network using PyTorch.
- Evaluate model performance using validation data.
- Experiment with different hyperparameters to improve accuracy.
- Understand the workflow of a deep learning image classification project.

---

## Project Description

This workshop focused on training a neural network to classify images into two categories: Chihuahua and muffin.

During the project, I learned how to preprocess images, organize datasets, train a model, evaluate predictions, and improve the model by adjusting different training parameters such as learning rate, batch size, and number of epochs.

I also compared my improved model with the original workshop notebook to better understand how different training choices affect performance.
