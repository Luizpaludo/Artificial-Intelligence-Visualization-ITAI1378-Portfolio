# Module 08: Visual Language Models

## Overview

This module introduced Visual Language Models (VLMs), which combine computer vision and natural language processing to understand both images and text. During this lab, I explored how these models connect visual and textual information to perform tasks such as image classification, image search, caption generation, and visual question answering.
