# Module 02: Image Fundamentals and Processing

## Overview

This module introduced the fundamental concepts of digital images and image processing. Through hands-on activities and research, I learned about different image formats, how they store image data, and how choosing the correct format depends on the intended application.

The activities in this module also encouraged creativity by presenting technical concepts in an engaging way while improving my understanding of image processing.

---

## Learning Objectives

After completing this module, I was able to:

- Understand the characteristics of common image formats.
- Compare image quality and file compression methods.
- Explain when different image formats should be used.
- Develop creative ways to communicate technical concepts.
- Improve research and presentation skills.

---

## Activities

### Activity 01 – Kingdom of Image Formats

This activity explored four common image formats (JPEG, PNG, BMP, and TIFF) through a creative "royal banquet" menu. Each format was presented as a different dish while explaining its characteristics, compression method, advantages, and common applications.

## What I Learned

This module helped me better understand how digital images are stored and why different formats are used in different situations.
