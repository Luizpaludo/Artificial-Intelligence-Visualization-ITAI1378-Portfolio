# Activity 01: Kingdom of Image Formats

## Overview

The purpose of this activity was to learn about the most common image formats used in computer vision and digital imaging. Instead of creating a traditional report, the assignment encouraged creativity by presenting the information in the form of a medieval royal banquet menu.

For this project, I selected the **Kingdom of Image Formats** challenge and created a menu where each dish represented a different image format: JPEG, PNG, BMP, and TIFF.

---

## Objectives

After completing this activity, I was able to:

- Compare different image formats.
- Understand lossy and lossless compression.
- Explain when each image format should be used.
- Present technical information in a creative and engaging way.
- Improve my research and presentation skills.

---

## Project Description

The project compares four popular image formats by describing each one as a special dish served at a royal banquet.

Each format includes its main characteristics, compression method, advantages, disadvantages, and common applications.

The formats presented are:

- **JPEG** – A compressed format that offers good image quality with smaller file sizes, making it ideal for websites, social media, and everyday photography.
- **PNG** – A lossless format that preserves image quality and supports transparent backgrounds, making it a popular choice for logos and web design.
- **BMP** – An uncompressed format that maintains the original image quality but creates much larger files, making it useful for image editing and Windows applications.
- **TIFF** – A professional image format that preserves excellent image quality, making it suitable for photographers, graphic designers, and high-resolution printing.
