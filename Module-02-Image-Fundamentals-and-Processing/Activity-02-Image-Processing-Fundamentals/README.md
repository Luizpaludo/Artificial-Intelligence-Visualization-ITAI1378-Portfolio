# Activity 02: Image Processing Fundamentals

## Overview

The purpose of this lab was to understand how digital images are represented and processed by computers. Throughout the notebook, I explored several image processing techniques, including image representation, grayscale conversion, brightness and contrast adjustments, filtering, histogram analysis, geometric transformations, and image enhancement.

The lab also introduced the connection between traditional image processing techniques and modern artificial intelligence tools.

---

## Objectives

After completing this activity, I was able to:

- Understand how computers represent images as numerical matrices.
- Apply basic image processing operations.
- Work with different image enhancement techniques.
- Explore geometric image transformations.
- Compare traditional image processing methods with AI-based image editing.
- Reflect on real-world applications of image processing.

---

## Project Description

This lab was completed using a Jupyter Notebook in Google Colab. During the exercises, I analyzed image properties, worked with RGB channels, converted images to grayscale, adjusted brightness and contrast, applied convolution filters, analyzed image histograms, and experimented with image enhancement techniques.

The final part of the activity explored how these traditional image processing methods relate to modern AI image generation and enhancement tools.

## What I Learned

This lab helped me understand that computers process images as matrices of numerical values instead of seeing them the way humans do. I learned how mathematical operations can change pixel values to create different visual effects, such as increasing brightness, sharpening images, or improving contrast.

One of the most interesting parts of the lab was understanding how traditional image processing techniques are connected to modern AI tools. Even though AI can perform many image editing tasks automatically, this activity helped me understand the mathematical operations that make those improvements possible.
